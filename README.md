# 日历 (CalendarApp)

An Android calendar app built with Jetpack Compose, featuring a Chinese lunar calendar view and local event management.

- **Package**: `com.calendar.cc`
- **Min SDK**: 26 · **Target/Compile SDK**: 36
- **UI**: Jetpack Compose (Material 3)

## Building

1. Open the project root in Android Studio (Ladybug/2024.2+ recommended for compileSdk 36), **or** build from the CLI.
2. The Gradle wrapper jar/script isn't included in this bundle. Generate it once with a local Gradle install:
   ```
   gradle wrapper --gradle-version 8.9
   ```
   or just open the project in Android Studio, which will regenerate `gradlew` automatically.
3. `./gradlew assembleDebug` to build, or run directly from Android Studio.

## Note on `DiagLogger` / `CrashApp`

`DiagLogger.java` and the reflection calls in `CrashApp.attachBaseContext` (looking for `CodeSlotLoader`, `HotSwapLoader`, `DebugHostSupport`) are development-time hooks generated by the AI IDE ("Yima IDE") this project was built with — they broadcast diagnostic logs to that IDE for live debugging and no-op safely (via `try/catch`) when those classes/the IDE aren't present, which is the case in this exported bundle. They're harmless to ship, but if you're open-sourcing this and don't want any broadcast-based diagnostics in the release build, you can safely delete `DiagLogger.java` and the corresponding `Class.forName(...DiagLogger...)` block in `CrashApp.java`.
